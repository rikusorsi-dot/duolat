# Duolat — латышский вслух

Прототип PWA-тренажёра латышского языка для русскоговорящих взрослых.
Короткие уроки по 3–5 минут, путь из уроков по порядку. В каждом уроке есть задание
«Скажи вслух»: пока фраза не произнесена в микрофон, урок не засчитывается.

> ⚠️ **Все латышские тексты в `content.json` — черновик и требуют проверки носителем языка.**

## Что внутри

| Файл | Что это |
|---|---|
| `content.json` | Все уроки и фразы. Править тексты — только здесь. |
| `index.html`, `styles.css`, `app.js` | Приложение (без сборки и без зависимостей). |
| `manifest.webmanifest`, `sw.js`, `icons/` | Установка на телефон и работа без интернета. |
| `tools/make-icons.mjs` | Перегенерировать иконки (нужен Playwright). |

## Задания

- `choose` — выбрать перевод;
- `listen` — послушать и выбрать (без латышского голоса на телефоне превращается в чтение);
- `build` — собрать фразу из слов;
- `speak` — сказать вслух. Обязательно минимум одно в уроке.

## Как работает «Скажи вслух»

1. Если браузер умеет распознавать речь (Chrome на Android) — фраза распознаётся на `lv-LV`
   и сравнивается с образцом. После 3 неточных попыток можно засчитать вручную: фраза ведь сказана.
2. Если распознавания нет или оно не работает (часто на iPhone) — приложение слушает микрофон
   и засчитывает, когда слышит голос. Запись можно прослушать и сравнить с образцом.
3. Если микрофона нет совсем — показывается понятное сообщение, урок не засчитывается.

Озвучка — `speechSynthesis` с латышским голосом. Если голоса нет, это видно на экране
«Проверить звук и микрофон». Можно подложить живые записи: файл в `audio/` и строка в разделе
`audio` в `content.json`.

## Прогресс

Хранится только на телефоне (`localStorage`): пройденные уроки, опыт, серия дней подряд.
Без регистрации и без сервера.

## Обновление

После изменения `app.js`/`styles.css` увеличь `CACHE` в `sw.js` (например, `duolat-v2`),
чтобы телефоны получили новую версию. `content.json` обновляется сам при наличии интернета.

## Локальный запуск

```
npx http-server -c-1 .
```
и открыть http://localhost:8080 (микрофон работает только на `localhost` или по `https`).
